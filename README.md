# Playground — Creative Website

A responsive, single-page creative website starter built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Deploy to Vercel

1. Put these files in a Git repository.
2. Import that repository in the Vercel dashboard.
3. Keep the framework preset as **Other** (static site).
4. Leave the build command and output directory empty; the site is served from the project root.
5. Deploy.

The site is mobile responsive and includes a small interactive color palette.
